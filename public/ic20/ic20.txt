1.What does express.json() do, and what would happen to req.body in your POST route without it?
express.json() is build in middle ware that reads the raw body of incoming request with a "content-Type: application/json" header, parses the JSON text
into a javaScript object, and attaches it to req.body




2.What is the difference between HTTP status 200 and 201? When would you use each?
HTTP status 200 means the request succeeded and the response carries the result. 
201 means that the request succeeded and a new resource was created as a result.
you typically use 200 for request that read or change things without creating anything new and then you use 201 when a POST 
creates a new resource
